## ⚠️ ควรแก้ก่อนเพิ่มของใหม่

### 1. คิวรี recursive วนไม่จบ = แท็บค้างถาวร (ไม่มีทางกู้)
`useDatabase.ts` รัน sql.js บน main thread ตรง ๆ (`runQuery` เรียก `db.exec` ใน event handler ของ
[QueryConsole.tsx:69](src/components/QueryConsole.tsx#L69)) และคดี 16 สอน `WITH RECURSIVE` โดยตรง
ผู้เล่นที่ลืมเงื่อนไขหยุด (ซึ่งคือ**ทั้งจุดประสงค์ของบทเรียนนั้น**) จะทำให้แท็บค้าง กด "ล้าง" ไม่ได้ ปิดแท็บอย่างเดียว
โน้ตที่ยังไม่ถูก flush ก็หายด้วย — ดูข้อ **H1** ด้านล่างเป็นทางแก้

### 2. `sqlGuard` เป็น regex คำเดี่ยว — false positive ในคดีจริง
[sqlGuard.ts:1](src/lib/sqlGuard.ts#L1) จับคำว่า `delete|update|insert|…` ทุกที่ในสตริง
แปลว่า `WHERE note LIKE '%update%'` หรือคอลัมน์ชื่อ `updated_at` จะถูกบล็อกทั้งที่เป็นคิวรีอ่านล้วน
(DB อยู่ใน memory ฝั่ง client ล้วน ไม่ใช่ช่องโหว่ความปลอดภัย แต่เป็นบั๊ก UX)
ทางแก้ราคาถูก: strip string literal + comment ออกก่อน แล้วเช็คว่า statement **ขึ้นต้น**ด้วย `SELECT`/`WITH` เท่านั้น

### 3. ไม่มีอะไรพิสูจน์ว่า 16 คดียังตอบถูกอยู่
`buildCases()` แทนชื่อคน/สถานที่ด้วย string replace เรียงคีย์ยาว→สั้น (README เตือนเคส `Old Town` vs `Old Town Wall` ไว้เอง)
ถ้าเพิ่มสถานที่ใน `seed.ts` แล้วลืมต่อ slot ใน `places.ts` คดีจะพังเงียบ ๆ และรู้ตอนผู้เล่นเจอเท่านั้น
→ ดูข้อ **H3**

### 4. โฟลเดอร์ `ืnote/` สะกดผิด (มีอักขระไทย `ื` นำหน้า)
อยู่ใน repo แล้ว (commit `7b53cc4`) ควร `git mv` ไปเป็น `note/` ให้ตรงกับ `note/suggest-feature/` ที่เพิ่งสร้าง

## 🟢 Quick win (< ครึ่งวัน)

### Q1 — คลิกค่าในตารางผลลัพธ์ = เติมลงช่องคำตอบ

- **ทำไม**: ชื่อคน/สถานที่**สุ่มใหม่ทุกรอบ** ผู้เล่นต้องพิมพ์ชื่อแปลก ๆ อย่าง `Amber Hardware` ตามจากตารางเอง
  และ `matchesAnswer` เทียบแบบ exact string ([normalize.ts:7](src/lib/normalize.ts#L7)) — พิมพ์ผิดตัวเดียวคือ "ยังไม่ใช่"
  ทั้งที่ผู้เล่นหาเจอแล้ว นี่คือ friction ที่โครงสร้างเกมสร้างขึ้นเอง
- **แตะ**: [ResultTable.tsx](src/components/ResultTable.tsx), [VerdictCard.tsx](src/components/VerdictCard.tsx), [GameBoard.tsx](src/components/GameBoard.tsx) (ส่ง prop เหมือน `insertRequest`)
- **effort**: S

- **อะไร**: คลิกชื่อคอลัมน์ = แทรกข้อความนั้นที่ตำแหน่ง cursor ในช่องเขียน

  ท่อ `insertRequest` มีอยู่แล้วจากสมุดบันทึก ต่อยอดได้เลย
- **แตะ**: [SchemaPanel.tsx](src/components/SchemaPanel.tsx), [QueryConsole.tsx](src/components/QueryConsole.tsx)

## 🔵 Impact สูง

### H1 — ย้าย sql.js ไป Web Worker + timeout ตัดคิวรี
- **อะไร**: โหลด wasm และรันคิวรีใน worker, ฝั่ง UI ตั้ง timeout ~3 วิ ถ้าเกินให้ `worker.terminate()` แล้วสร้างใหม่จาก seed เดิม
  พร้อมข้อความ "คิวรีนี้วนไม่จบ — เช็คเงื่อนไขหยุดของ `WITH RECURSIVE`"
- **ทำไม**: แก้ปัญหาข้อ 1 ข้างบน และเปลี่ยนจุดตายให้กลายเป็น**บทเรียน** — ข้อความ timeout สอนตรงจุดที่ผู้เล่นพลาดพอดี
  แถมได้ผลพลอยได้: seed 617 บรรทัด + init wasm ไม่บล็อก first paint อีกต่อไป
- **แตะ**: `src/workers/db.worker.ts` (ใหม่), [useDatabase.ts](src/hooks/useDatabase.ts), [QueryConsole.tsx](src/components/QueryConsole.tsx)
- **effort**: M
